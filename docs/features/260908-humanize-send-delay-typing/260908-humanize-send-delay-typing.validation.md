# 260908-humanize-send-delay-typing 用户验证

## 验证说明

- 验证对象：拟人化两阶段发送——阅读延迟（sendDelay）+ 输入状态指示（typingIndicator）+ 按机器人覆盖 + supersede 静默取代
- 环境/前置条件：dsh Host 加载本 fork 插件（lib/ 已构建）；至少接入 1 个支持输入状态的渠道机器人（推荐 Telegram 或 QQ 私聊）与 1 个无输入状态渠道机器人（如飞书/钉钉）；全局拟人化设置面板可用

## 验证项
