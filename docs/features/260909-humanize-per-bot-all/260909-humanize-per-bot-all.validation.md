# humanize-per-bot-all 用户验证

## 验证说明

- 验证对象：拟人化设置逐 bot 全量覆盖（8 项）＋ 全局面板与逐 bot 编辑器共享同一套字段模块（格式统一、探索预设、保存时校验）
- 环境/前置条件：dsh web GUI（http://127.0.0.1:4175），安装本 fork 构建产物（`npm run build` 后的 lib/）；至少一个渠道已配置机器人（如 Telegram / 钉钉）；无则写“无”
- 自动化已覆盖（无需手动验证）：字段渲染与 aria 标签、保存 payload 结构（只写自定义 key / 完整 sendDelay 毫秒值）、范围与交叉校验错误文案、未保存草稿在 15s 轮询刷新下保留、快照 normalizer 直通修复 —— 见 `test/client-humanize-ui.test.mjs`（8 用例）
