# Telegram 语音消息投递 用户验证

## 验证说明

- 验证对象：agent 通过 `dsh_im_return_file` 投递音频时，Telegram 端呈现为**语音消息气泡**（圆形、可点播放）而不是文件/音频附件。
- 环境/前置条件：
  - `lib/` 已重新构建，且 dsh 已重启加载新插件（link 部署，需重启生效）。
  - 已配置的 Telegram bot（私聊或群话题均可）处于连接状态。
  - 本地可执行 `fish-tts`（生成 `.mp3` / `.opus` / `.wav`）与 `ffmpeg`。
